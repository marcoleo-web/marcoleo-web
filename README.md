
# Marcoleo | Ingeniería y Desarrollo de Software

Landing page oficial para **Marcoleo**, una agencia enfocada en el desarrollo de software a la medida, aplicaciones web y plataformas SaaS.

## 🚀 Tecnologías Utilizadas

- **HTML5** y **JavaScript** (ES6+)
- **Tailwind CSS** para el diseño responsivo
- **Google Fonts** (Inter y JetBrains Mono)

## 📦 Estructura del Proyecto

```text
├── index.html          # Estructura principal de la página
├── app.js              # Lógica de interactividad y formularios
└── dist/
    └── styles.css      # Estilos compilados de Tailwind
